# TaskFlow 🚀

TaskFlow is a modern and interactive To-Do List web application designed to help users manage daily tasks efficiently with a clean and responsive user interface.

Built using HTML, CSS, and Vanilla JavaScript, the project focuses on productivity, simplicity, and user experience.

---

## ✨ Features

- ✅ Add, Edit, and Delete Tasks
- 📂 Task Categories
- 🔍 Real-Time Search
- 🎯 Priority Levels (High, Medium, Low)
- 📅 Deadline Management
- ⚠️ Overdue Task Detection
- 📊 Task Statistics Dashboard
- 📈 Progress Bar Tracking
- 🗂️ Category Sidebar
- 💾 Local Storage Support
- 📱 Responsive Design
- 🌙 Modern Dark UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Local Storage API
